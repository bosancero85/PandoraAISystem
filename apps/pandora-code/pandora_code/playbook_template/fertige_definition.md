# Fertige Definition

Ein Schritt ist erst `[x]`, wenn alle zutreffenden Punkte erfüllt **und geprüft** sind. „Gut genug“ und
„den Rest kann der Nutzer machen“ gelten nicht.

## Pro Schritt

- [ ] Ergebnis liegt vollständig vor (keine Platzhalter, keine `TODO`s, keine abgeschnittenen Dateien)
- [ ] Datei wurde nach dem Schreiben erneut gelesen und stimmt mit der Absicht überein
- [ ] Code läuft: Programm gestartet oder Import geprüft, keine Fehlermeldung
- [ ] Zugehörige Tests geschrieben und **ausgeführt**, alle grün (Ausgabe gesehen, nicht angenommen)
- [ ] Formatierung und Stil passen zum restlichen Projekt
- [ ] Datei liegt am richtigen Ort laut `ablage.md`
- [ ] `session_handoff.md` ist aktualisiert

## Projektabschluss (zusätzlich)

- [ ] Alle Punkte der Checkliste stehen auf `[x]`
- [ ] Alle Tests laufen in einem Durchgang grün
- [ ] `README.de.md`: Zweck, Installation, Start, Beispiel, Tests
- [ ] `LICENSE` vorhanden und passend zu `project.toml`
- [ ] `.gitignore` vorhanden und passend zur Sprache
- [ ] `project.toml` vollständig und aktuell
- [ ] Git-Repository ist bereit (`git init`, sinnvolle erste Commits) – Veröffentlichung nur auf Wunsch des Nutzers
- [ ] Abschlussbericht: was gebaut wurde, was geprüft wurde, was bewusst offen bleibt
