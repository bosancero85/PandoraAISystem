# Interview

Wird zu Projektstart durchgegangen. Regeln: nur offene Fragen stellen, alle in **einer** Nachricht, Antworten
sofort in `project.toml` und unten im Protokoll festhalten. Lässt der Nutzer etwas offen, wird eine begründete
Annahme notiert und als solche markiert.

## Fragen

1. Was soll gebaut werden, in ein bis zwei Sätzen? Wer benutzt es?
2. Welche Sprache, welche Laufzeit oder Frameworks, welche Zielsysteme (Windows/Linux/macOS)?
3. Was gehört zwingend dazu (Muss), was ausdrücklich nicht (Nicht-Ziele)?
4. Gibt es vorhandenen Code, Vorlagen oder Dateien, die verwendet werden sollen?
5. Wie erkennt man, dass es funktioniert (Beispielaufruf, erwartetes Ergebnis, Tests)?
6. Welche Lizenz? Welcher Projektname? Soll ein GitHub-Repository vorbereitet werden?
7. Gibt es Einschränkungen (Abhängigkeiten, Offline-Betrieb, Größe, Zeit)?
