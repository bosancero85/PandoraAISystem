# Interview / Anforderungen

- Framework: CustomTkinter, benutzerfreundlich
- Bedienelemente: Start/Stop-Button, Ordnerauswahl, Ladebalken, Ausgabe-Log
- Funktion: Führt für den gewählten HTML-Projektordner `python -m http.server 8080` aus
- Ergebnis: eine .exe für Windows
- Schließen: Fenster in den Tray legen
- Nutzung: HTML-Seiten (z. B. Ollama Mobile Chat) vom Laptop ans Handy ausliefern
- Umsetzung: Server läuft im Programm selbst (kein externes Python nötig), gleiches Verhalten wie `http.server`
