Pandora® AI System

Dein lokales KI-Werkzeugset rund um Ollama: Modelle installieren, per Handy chatten, im Terminal programmieren. Ohne Cloud, ohne Konto.

Die vier Werkzeuge

Jedes Werkzeug funktioniert allein. Zusammen ergeben sie eine komplette lokale KI-Umgebung. Klicke auf ein Bild für die große Ansicht.

  • Ollama Browser Chat

    Chat-Oberfläche für Handy und Desktop, ohne Abhängigkeiten. Chats bleiben lokal im Browser.

    • Streaming, Markdown, Code-Blöcke, Artefakte
    • 7-Segment-Token-Anzeige mit Kontextwarnung
    • Diktieren, Anhänge, Export, App-Installation (PWA)
    Ordner auf GitHub →

  • Mini Webserver

    Liefert einen Ordner im Netzwerk aus und ist die Brücke zwischen Handy und Ollama.

    • HTTPS mit eigener Zertifizierungsstelle, nötig fürs Diktieren
    • Ollama-Weiterleitung mit Streaming
    • Start/Stopp, Log, Tray-Symbol
    Ordner auf GitHub →

  • Ollama Models Library & Installer

    Grafische Oberfläche statt ollama pull, mit der kompletten Ollama-Bibliothek.

    • Suche, Kategorien, Größenwahl je Modell
    • Speicherschätzung vor dem Download
    • Batch-Installation mit Fortschritt
    Ordner auf GitHub →

  • Pandora® Code

    Lokaler Coding-Agent fürs Terminal, nur mit der Python-Standardbibliothek.

    • Read, Write, Edit, Bash, Grep, Todo mit Diff-Vorschau
    • Modell-Router, AST-Graph, Vektor-RAG, Auto-Fix
    • Subagenten, Hooks, MCP, optionale Sandbox und TUI
    Ordner auf GitHub →

Live-Simulator

Das ist die echte Chat-App, direkt in dieser Seite. Statt Ollama antwortet ein kleiner Simulator, also brauchst du hier nichts zu installieren.

Probier es aus

Tippe unten in der App etwas ein oder nutze eine Vorlage:

  • IN (cyan): Tokens der letzten Anfrage
  • OUT (magenta): Tokens der Antwort, zählt live mit
  • Σ (grün): Summe in diesem Chat
  • Wird IN gelb oder rot, ist das Kontextfenster fast oder ganz voll

Die Antworten sind vorgefertigt. Mit echtem Ollama kommen sie von deinem Modell. Mikrofon und Anhänge sind in der Demo ausgeschaltet.

Schnellstart

  1. Ollama installieren und mit dem Models Installer ein Modell holen, zum Beispiel qwen2.5-coder:7b.
  2. Mini Webserver starten, den Ordner des Chats wählen, HTTPS an lassen und „Server starten“ klicken.
  3. Am Handy im selben WLAN die angezeigte Adresse öffnen, zum Beispiel https://YOUR - IP/ollama.html. Die Zertifikatswarnung einmal bestätigen.
  4. Im Terminal pandora code starten und mit dem Agenten programmieren.
